### PRODUK UNGGULAN: D-ASSET — WebGIS Pengelolaan Aset PDAM
> Website produk: https://webgis-pdam.devetek.app/
> Tagline: "Kelola Aset PDAM dalam Satu Peta Interaktif"

**Deskripsi:**
Solusi pemetaan aset, manajemen pelanggan, survey lapangan, dan monitoring real-time — terintegrasi dalam satu platform. Siap integrasi dengan DEVETEK IoT (HELIOS).

**Tantangan PDAM yang Dijawab:**
- Data aset tersebar di Excel, CAD, dan peta kertas
- Sulit melacak kondisi dan lokasi aset secara real-time
- Laporan manual memakan waktu dan rawan kesalahan
- Kesulitan koordinasi antara tim lapangan dan kantor

**Fitur Utama:**

| Fitur | Deskripsi |
|-------|-----------|
| **Peta Interaktif** | Visualisasi 10+ jenis aset dengan layer dinamis dan styling custom |
| **Manajemen Pelanggan** | Data pelanggan terintegrasi dengan lokasi spasial di peta |
| **Survey Lapangan** | Template dinamis, multi-geometri, upload foto & dokumen |
| **Monitoring Aset** | Pencatatan tekanan, debit, kualitas air dengan checklist harian |
| **Elevation Profile** | Analisa profil ketinggian jaringan pipa untuk perencanaan |
| **Laporan & Export** | Generate laporan PDF/Excel otomatis dengan template |
| **Integrasi IoT** | Terhubung dengan DEVETEK HELIOS untuk monitoring sensor real-time |

**Keamanan Data:**
- Enkripsi HTTPS end-to-end
- Isolasi data: setiap PDAM punya schema database terpisah
- Role-Based Access 4 level: Superadmin, Admin, Editor, Viewer
- Audit trail: semua perubahan tercatat dengan timestamp

**Integrasi QGIS Desktop:**
- QGIS untuk digitasi masif, koreksi geometri kompleks, snapping presisi, styling GIS profesional
- WebGIS untuk survey lapangan, viewing cepat, monitoring — akses dari browser, tanpa instalasi, mobile-friendly
- Satu database PostGIS: edit di QGIS langsung terlihat di WebGIS dan sebaliknya
- Download project QGIS (.qgz) dengan kredensial tertanam

**Ekosistem Terintegrasi:**
- D-ASSET (WebGIS PDAM) ↔ DEVETEK HELIOS (IoT Cloud) ↔ D-IBS (Billing) ↔ QGIS Desktop ↔ Database Terpusat

**Implementasi 4 Langkah:**
1. Setup tenant (environment khusus per PDAM)
2. Import data (CSV, GeoJSON, Shapefile)
3. Konfigurasi (referensi, zona wilayah, hak akses)
4. Mulai operasi

### PRODUK UNGGULAN: DEVETEK HELIOS — Platform IoT End-to-End
> Website produk: https://iot.devetek.app/
> Tagline: "Monitor. Analisa. Kendalikan."

#### Ekosistem: Dua Pilar, Satu Solusi

**1. DEVETEK HELIOS (Cloud Platform — Subscription per Node)**
- Dashboard custom & widget builder (6+ tipe widget, SQL editor, dual data source PostgreSQL + ClickHouse)
- WebGIS dengan OpenLayers + PostGIS (upload SHP, GeoJSON, KML, DMA boundary, live sensor overlay)
- AI Analytics & Early Warning System (Random Cut Forest anomaly detection, forecasting 7 hari, ML dashboard)
- Smart Alert 3 lapis: threshold rules → deteksi offline otomatis → ML anomaly detection
- Notifikasi via WhatsApp, Email, Telegram, In-app, Webhook
- Laporan otomatis PDF/Excel (multi-sheet XLSX, chart preview, filter cascading, template reusable)
- Audit trail lengkap (semua aksi CREATE/UPDATE/DELETE/LOGIN tercatat, export CSV untuk audit BPKP)
- Kontrol valve & pompa jarak jauh (ON/OFF/PULSE via MQTT)
- Sinkronisasi ke server PDAM (PostgreSQL, MySQL forwarding, Webhook, REST API)
- Telemetry real-time (auto-refresh 5s-5m, cascading filter, CSV export)
- Multi-tenant, multi-zona (1 PDAM = banyak zona DMA, masing-masing punya dashboard/peta/laporan sendiri)
- Role-based access (Admin & Tenant)
- Device management (auto-discovery, pairing workspace, hardware catalog, health monitoring, relay control, sensor calibration, OTA firmware update)
- Integrasi server pelanggan (Webhook, API)
- 60+ halaman dokumentasi terintegrasi dalam platform

**Performa:**
- < 500ms rata-rata respons API
- 10K+ data point / detik
- 99.9% uptime SLA
- 24/7 monitoring real-time
- Data retention configurable (default 3 bulan raw, summary permanen)

**Konektivitas Terbuka (tidak terkunci vendor):**
- MQTT (ESP32, Arduino, Raspberry Pi)
- TCP/IP (Teltonika FM, PLC, Modbus Gateway)
- HTTP/HTTPS (REST API, Webhook, Any Device)

**Tools & Teknologi:**
ESP32, Arduino, Raspberry Pi, PLC, Teltonika FM, MQTT, TCP/IP, HTTP/HTTPS, Webhook, REST API, PostgreSQL, MySQL, ClickHouse, Firebase, Modbus RTU, 4G/2G Cellular, LoRa, RS485, Analog 4-20mA, SHP/GeoJSON, XLSX Export, OpenLayers, ECharts
